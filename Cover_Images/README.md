# Cover Images

This folder contains the cover images used in the Image Steganography project.

A cover image acts as the carrier image into which confidential image information is embedded using Discrete Wavelet Transform (DWT) and Singular Value Decomposition (SVD).

### Available Images

| File | Description |
|---|---|
| `pic20.jpg` | Cover image sample |
| `pic21.jpg` | Cover image used in the original implementation |
| `pic22.jpg` | Cover image sample |
| `pic23.jpg` | Cover image sample |
| `pic24.jpg` | Cover image sample |

Any of these images can be used as a cover image by providing its path during encoding.

**Note:** The selected cover image is resized to match the dimensions of the hidden image before embedding.
