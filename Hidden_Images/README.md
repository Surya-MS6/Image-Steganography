
# Hidden Images

This folder contains the secret images used in the Image Steganography project.

These images are embedded into a selected cover image using Discrete Wavelet Transform (DWT) and Singular Value Decomposition (SVD). Each image represents a different category that can be selected during the encoding and decoding process.

### Available Images

| File | Category |
|---|---|
| `pic1.jpg` | School |
| `pic2.jpg` | Hospital |
| `pic3.jpg` | Military Base |
| `pic4.jpg` | National Park |
| `pic5.jpg` | Armory |

The image paths and corresponding password information are maintained in `information.json`.
